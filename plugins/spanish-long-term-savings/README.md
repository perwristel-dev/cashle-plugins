# Spanskt långsiktigt sparande (SIALP/CIALP)

Använd posten för ett kvalificerat försäkrings- eller bankavtal enligt den
spanska långtidsplanen. Inmatningen använder marknadsvärde, kvarvarande
insatt kapital och datum för planens första premie eller insättning.
Ange också årets insättningar om planen börjar efter årets början. Kontot
beräknar högst 5 000 EUR nya insättningar per år och ett konto per ägare.
Planen förutsätter att försäkringsbolaget eller banken uppfyller villkoren,
inklusive den avtalsenliga garantin på minst 85 procent.

Endast fullständigt avslut ingår. Efter fem år är positiv avkastning
skattefri. Ett tidigare avslut ger vanlig spansk skatt på vinsten. Prognosen
bokför skatten vid årsavräkningen. Nettoförlust bedöms vid avslut. Tidigare
undantagna vinster och överföring mellan försäkringsbolag ligger utanför
modellen. För nyår gäller samma nominella insättningsgräns som år 2025.
